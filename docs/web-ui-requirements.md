# CatfeeAgents 控制台 · UI/UX 需求清单

> 用途：交给 UI AI / 设计师重做界面时作为输入文档。
> 原则：这是**设备与任务管理控制台**，不是营销落地页。信息密度、状态可读性、操作安全性优先于装饰。

## 1. 产品定位

- 产品名：CatfeeAgents 控制台（CatfeeAgents Web 控制台）
- 使用者：管理员 / 运维 / 测试人员
- 管理对象：已授权接入的 Android Agent 设备
- 核心目标：
  1. 一眼看到哪些设备在线、哪些任务在跑
  2. 给指定设备下发任务
  3. 实时看到任务执行步骤与结果
  4. 暂停 / 继续 / 停止任务
  5. 查看历史事件、审计记录
  6. 注册新设备、撤销设备授权
- 非目标：公网营销页、任意远程 Shell、绕过设备授权的隐蔽控制。

## 2. 信息架构

```text
登录
└─ 工作台
   ├─ 概览
   ├─ 设备
   │  └─ 设备详情
   ├─ 任务
   │  └─ 任务详情
   ├─ 事件日志
   └─ 设置
      ├─ 账号
      ├─ 系统信息
      ├─ Agent 接入
      ├─ 安全说明
      └─ 审计日志
```

未来可选：设备组、任务模板、截图查看器、RBAC、全局搜索 / 命令面板。

## 3. 设计系统

### 3.1 品牌

- Logo：黑白红猫咪 + 手机 + 齿轮（`web/console/public/brand/logo.png`）
- 品牌色：黑 `#111827`、红 `#E11D2E`、白 `#FFFFFF`
- 风格关键词：扁平、克制、工程感、可信、可审计
- 不再使用蓝色作为主色；红色只用于强调、危险状态和关键操作

### 3.2 颜色 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| canvas | `#F7F8FA` | 页面背景 |
| surface | `#FFFFFF` | 卡片、侧栏、弹窗 |
| ink | `#111827` | 主文字、主按钮 |
| muted | `#6B7280` | 次文字 |
| faint | `#9CA3AF` | 辅助说明、时间 |
| line | `#E5E7EB` | 1px 描边 |
| subtle | `#F1F3F5` | 悬停、标签底色 |
| brand | `#E11D2E` | 品牌强调、进行中 |
| success | `#16A34A` | 在线、成功 |
| warning | `#D97706` | 等待、警告、暂停 |
| danger | `#DC2626` | 失败、撤销、停止 |
| violet | `#7C3AED` | 暂停、特殊事件 |

状态底色统一使用 8%–12% 透明度的同色系，不要大面积高饱和色块。

### 3.3 字体

- 中文：系统字体 / PingFang SC / Microsoft YaHei / Noto Sans SC
- 英文与数字：Inter 或系统无衬线
- ID、时间、JSON、端口、Token：等宽字体
- 建议层级：
  - 页面标题 24–28px / 700
  - 卡片标题 14–15px / 600
  - 正文 13–14px / 400
  - 辅助 11–12px
  - 微标签 10–11px / 600 + 字距
  - KPI 数字 30–36px / 700 + tabular-nums

### 3.4 空间与形状

- 8pt 网格；常用间距 4 / 8 / 12 / 16 / 20 / 24 / 32
- 圆角：8 / 12 / 14 / 16 / 20
- 描边：1px `line`；不使用重阴影
- 允许非常轻的 hover 阴影，但不要卡片悬浮感
- 图标：Lucide 线性图标，1.75px 左右描边

### 3.5 响应式

- ≥1280：完整侧栏 + 多列内容
- 768–1279：可折叠侧栏 / 双列
- <768：顶部栏 + 抽屉导航 + 底部 5 项导航；卡片单列
- 表格在移动端必须降级为卡片，不允许横向挤压
- 最小点击区域 40×40px

### 3.6 可访问性

- 正文对比度 ≥ 4.5:1
- 所有交互有键盘 focus 态
- 状态不能只靠颜色区分，必须有文字
- 尊重 `prefers-reduced-motion`
- 动效 150–220ms，不做大幅弹跳

## 4. 页面需求

### 4.1 登录页

- 桌面：左侧品牌区（黑底、Logo、产品主张），右侧登录表单
- 移动：单列，Logo + 表单
- 字段：用户名、密码、显示/隐藏密码
- 状态：默认、输入错误、登录中、服务不可用
- 错误：用户名或密码错误；会话过期
- 文案：强调“仅限已授权设备与内部环境”
- 不需要注册、忘记密码、第三方登录

### 4.2 全局框架

- 桌面侧栏：
  - Logo + 产品名
  - 导航：概览 / 设备 / 任务 / 事件日志 / 设置
  - 当前项高亮（浅底 + 红点或左侧红线）
  - 底部：控制台连接状态（实时/未连接）、用户信息、退出
- 移动：
  - 顶部：菜单、Logo、实时状态
  - 抽屉：完整导航 + 用户
  - 底部：5 项图标导航
- 页面头部：标题、说明、右侧操作区（刷新、新建、注册等）

### 4.3 概览

目标：30 秒内回答“现在系统健康吗？有什么在跑？出了什么事？”

- 4 个 KPI 卡：
  - 在线设备：`在线 / 总数`
  - 活跃任务：数量
  - 今日事件：数量
  - 今日失败：数量
- “最近任务”列表：标题、设备、类型、状态、时间、耗时
- “设备状态”面板：设备名、型号、最后心跳、状态
- “实时事件”列表：级别、事件类型、设备、摘要、时间
- 操作：刷新、新建任务、注册设备
- 空状态：没有设备 / 没有任务 / 没有事件，分别有下一步 CTA
- 可选增强：设备在线率环形图、任务状态分布、7 日趋势

### 4.4 设备列表

- 状态筛选：全部 / 在线 / 离线 / 待接入 / 已撤销，带数量
- 搜索：名称、设备 ID、型号
- 视图：桌面卡片网格（建议 3 列），移动单列
- 设备卡字段：
  - 名称、设备 ID
  - 状态（在线/离线/待接入/已撤销）
  - Android 版本、Agent 版本
  - 能力标签（accessibility/root/ocr/screenshot…）
  - 最后心跳
- 操作：注册设备
- 注册设备弹窗：
  - 一次性注册码（大号等宽）
  - 有效期 10 分钟
  - Agent WebSocket 地址、设备注册接口
  - 复制按钮
  - “重新生成”
  - 明确提示：仅可使用一次
- 空状态、搜索无结果、加载骨架

### 4.5 设备详情

- 头部：设备名、状态、设备 ID、返回
- 操作：刷新、撤销授权（危险操作二次确认）
- 已撤销横幅：解释设备不会再接收任务
- 信息区：设备 ID、型号、Android、Agent 版本、最近心跳、最近在线、接入时间、授权状态
- 能力标签区
- 最近任务列表（可跳转）
- 最近事件列表（可展开 JSON）
- 最近控制指令：类型、状态、时间
- 撤销确认文案：说明会中断进行中的任务，且不可自动恢复

### 4.6 任务列表

- 状态筛选：全部 / 进行中 / 已暂停 / 失败 / 已完成 / 已停止，带数量
- 列表字段：标题、设备、任务类型、状态、创建时间、耗时
- 桌面可用表格/行列表；移动用卡片
- 操作：新建任务、刷新
- 新建任务弹窗：
  - 目标设备（仅未撤销；离线设备允许，提示会排队）
  - 任务标题
  - 任务类型：Agent 目标 / 设备诊断 / 应用流程
  - 目标描述（多行）
  - 超时时间：不限制（默认）/ 5 / 15 / 30 分钟 / 1 小时
  - 策略：允许截图（默认开）、允许 Root（默认关，说明高危）
  - 提交后：online 提示“已下发”，offline 提示“已排队”
- 空状态

### 4.7 任务详情

目标：像“飞行记录仪”一样还原执行过程。

- 头部：任务标题、设备、类型、当前状态
- 操作：暂停（running/accepted）、继续（paused）、停止（危险二次确认）、刷新
- 错误横幅：任务失败/中断原因
- 执行时间线：
  - 事件级别、事件类型、设备、时间
  - 可展开查看 JSON payload
  - 支持长列表滚动；运行中自动追加
  - 建议按 step 分组，显示工具名、结果摘要、耗时
- 任务信息：任务 ID、类型、创建人、创建/开始/结束时间、耗时、目标设备
- 执行策略：截图、Root、超时
- 下发参数 JSON
- 控制指令记录：TASK_ASSIGN / PAUSE / RESUME / STOP 及 ACK 状态
- 运行中显示 Live 标识
- 空事件状态

### 4.8 事件日志

- 筛选：级别（全部/INFO/WARN/ERROR/SECURITY/DEBUG）
- 类型过滤（前缀，如 `task.`）
- 设备过滤
- 实时开关 / Live 状态
- 事件行：级别、类型、设备、任务 ID、摘要、时间；展开 JSON
- 默认显示最近 200 条
- 空状态、加载态、自动滚动/不打断用户阅读
- 可选：导出、按时间范围、按任务过滤

### 4.9 设置

建议用分区或 Tab：

- 账号：头像/首字母、显示名、用户名、角色、创建时间、会话有效期
- 系统信息：版本、运行时长、Node、平台、设备/任务/事件数、SQLite 路径
- Agent 接入：WebSocket 地址、注册接口、控制台基地址、协议版本、心跳、注册码有效期
- 安全说明：默认密码、HTTPS/Secure Cookie、设备凭证、Root 默认关闭、日志脱敏
- 审计日志：操作、操作者、目标、时间；可刷新
- 关于：技术栈、开源/协议信息

### 4.10 未来页面（可选，不要求首版）

- 设备组 / 批量任务
- 任务模板
- 截图查看器（按需请求，短期 URL）
- RBAC 用户与权限
- 7 日趋势 / 任务成功率图表
- 全局命令面板（⌘K）

## 5. 状态与交互清单

### 设备状态

| 状态 | 文案 | 颜色 |
| --- | --- | --- |
| online | 在线 | success |
| offline | 离线 | muted |
| pending | 待接入 | warning |
| revoked | 已撤销 | danger |

### 任务状态

`queued` 已排队、`waiting_device` 等待设备、`accepted` 已接收、`running` 执行中、`paused` 已暂停、`stopping` 停止中、`stopped` 已停止、`succeeded` 已完成、`failed` 失败、`interrupted` 已中断、`expired` 已过期。

### 事件级别

`debug` / `info` / `warn` / `error` / `security`

### 指令类型

`TASK_ASSIGN` 下发任务、`TASK_PAUSE` 暂停、`TASK_RESUME` 继续、`TASK_STOP` 停止。

指令状态：`pending` 排队中、`sent` 已发送、`acked` 已确认、`failed` 失败、`expired` 已过期。

### 必须覆盖的页面状态

- 加载中：骨架屏，不要整页 spinner
- 空：说明 + 下一步 CTA
- 错误：可行动的错误信息 + 重试
- 未登录 / 会话过期：跳登录，保留 redirect
- 设备离线：任务创建提示排队
- 已撤销设备：禁止创建任务
- 长文本：截断 + tooltip / 展开
- JSON：等宽、可折叠、可复制
- 实时连接断开：显示“未连接”，自动重连

## 6. 核心用户流程

### 注册设备

1. 设备页点击“注册设备”
2. 生成 10 分钟一次性注册码
3. 复制注册码到 APK
4. APK 完成注册并上线
5. 设备列表出现新设备
6. 进入设备详情核对型号/能力

### 下发任务

1. 任务页点击“新建任务”
2. 选择设备、填写标题/类型/目标/策略
3. 提交
4. 在线设备立即下发；离线设备显示“等待设备”
5. 进入任务详情看实时时间线
6. 成功后查看结果；失败看错误与最后事件

### 控制任务

1. 任务详情点击暂停/继续/停止
2. 指令显示“已发送/已确认”
3. 任务状态以设备上报事件为准
4. 停止需要二次确认

### 撤销设备

1. 设备详情点击撤销
2. 二次确认（说明中断任务）
3. 设备状态变为已撤销
4. 设备不再接收任务/指令

## 9. 三个可选设计方向

### A. Swiss Control Room（推荐）

黑色侧栏 / 白色内容区 / 红色强调；强标题、细线网格、等宽数字；像专业监控台。适合“可信、工程感”。

### B. Editorial Light

暖白背景、超大页面标题、细分隔线、红黑点缀、更多留白；更像高端 SaaS 控制台，弱化“工具感”。

### C. Neo-brutalist Terminal

黑色粗描边、块状卡片、等宽字体、红黑高对比；个性最强，但长时间使用视觉疲劳风险更高。
