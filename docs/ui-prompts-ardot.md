# Catfee 双端 UI 生成提示词（Ardot）

> 用途：把下面两个代码块分别复制给 Ardot，生成 Android App 与 Web 控制台的高保真界面。
> 两个提示词都包含完整功能清单、菜单、页面状态和视觉规范。
> 如果 Ardot 一次生成内容过长，按每个提示词末尾的“分批建议”拆开发。

### 1.2 可直接复制的提示词

```text
你是一名资深移动端产品设计师，请为「CatfeeAgents」设计一套高保真 Android App UI。
这是已经上线的产品改版，不是概念稿，不要做营销页，不要生成登录/注册页。

【产品定位】
CatfeeAgents 是一个装在 Android 手机上的通用 Agent 工作台：
- 用户可以用一个输入框聊天、分析图片/文件；
- 需要操作手机时，Agent 自己请求一次授权，然后通过无障碍、Root 或手势执行任务；
- 用户可以在聊天流里实时看到 Agent 的思考、工具调用、步骤和结果；
- 用户可以在设置里配置模型、远程 Web 控制台、App 记忆和费用统计。

【目标用户】
- 需要让手机自动完成重复操作的重度用户；
- 测试/运维人员；
- 对隐私和授权比较敏感、但愿意使用自动化的人。

【设计目标】
1. 打开就是可用的对话界面，不先选 Chat / Agent 模式；
2. Agent 在做什么必须一眼可见：当前工具、第几步、耗时、是否暂停；
3. 长任务要可暂停、继续、停止，且不会误触；
4. 设置页信息密度高，但分组清楚，不让人迷路；
5. 黑白红品牌，克制、工程感、可信，不做花哨装饰。

【视觉方向】
- 只做 Light 主题。
- 画布 #F7F8FA，卡片 #FFFFFF，主文字 #111827，次文字 #6B7280，
  辅助文字 #9CA3AF，描边 #E5E7EB，品牌红 #E11D2E，
  成功 #16A34A，警告 #D97706，危险 #DC2626。
- 品牌红只用于：Logo、发送/运行状态、选中态、关键强调、危险提示。
- 扁平化：1px 描边、无重阴影、低饱和状态底色；允许极轻的 hover/pressed 态。
- 圆角：输入框 26dp，卡片 14–18dp，弹层 22–28dp，标签 999dp。
- 字体：中文系统字体 / Noto Sans SC；代码、工具名、设备 ID、时间用等宽字体。
- 8pt 网格；常用间距 4/8/10/12/14/16/20/24。
- 图标使用圆角线性图标，1.75px 左右描边。
- 最小点击区域 44×44dp；正文对比度 ≥ 4.5:1。
- 状态不能只靠颜色区分，必须有文字标签。

【画布】
- 主画板：393×852（iPhone 15 / 主流 Android 逻辑尺寸），所有页面单独 Frame。
- 页面命名：Android/01-首页-空状态、Android/02-聊天-执行中……
- 需要包含状态栏、手势条、底部安全区。
- 不要使用真实 API Key、真实设备 ID；示例数据用明显的假值。

【必须生成的页面】

A01 首页-空状态
- 顶部：Logo + “CatfeeAgents”（Catfee 黑色、Agents 红色），副标题
  “Chat & phone agent”；右侧圆形菜单按钮。
- 中间：白色欢迎卡，Logo、标题“开始对话”，说明
  “可以聊天、分析图片/文件；需要时 Agent 会请求一次授权，然后自己操作手机。”
- 底部输入区：附件按钮、多行输入框、发送按钮；
- 输入区下方：绿色圆点 + 当前模型名 + “切换”。
- 整体留白充足，但不要做成营销落地页。

A02 聊天-普通问答
- 用户消息右对齐，浅灰底，圆角 18dp，最大宽度 86%。
- 助手消息左对齐，白底、1px 描边；支持 Markdown 标题、列表、粗体、行内代码、
  代码块（深色底、顶部语言标签、复制按钮）。
- 助手消息下面有“复制”图标和推理过程折叠面板“思考过程”。
- 顶部会话标题行：当前会话标题 + `12.4K tok · 8.2K ctx · 01:24`。
- 不要显示多余的“AI 正在输入”占位，除非有流式内容。

A03 聊天-Agent 执行中
- 用户消息：“打开淘宝，找最便宜的 DDR4 3600 16G 内存”。
- 助手流式气泡：显示当前动作摘要。
- Activity 卡：
  - 标题“Activity · 12 steps”
  - 副标题“Working · ocr”
  - 右侧展开箭头
  - 展开后是纵向步骤卡：类型标签（THINK / TOOL / RESULT / SYSTEM / ERROR）、
    工具名、时间、正文；正文超过 3 行折叠，点击展开。
- 输入区切换为：暂停/继续按钮 + 停止按钮，发送按钮隐藏。
- 顶部状态显示红色呼吸点 + “Working on this device”。

A04 聊天-等待授权
- 聊天流中插入黄色授权卡：
  - 锁图标
  - 标题“允许控制手机？”或“允许使用无障碍操作手机？”
  - 说明“Agent 想读取当前屏幕内容 / 点击滑动 / 输入文字 / 打开应用”
  - 工具参数用等宽字体展示
  - 主按钮“允许”、次按钮“拒绝”
- 授权卡不要做成系统弹窗，保持在聊天流里。
- 输入区保持可用但发送禁用，显示提示“等待用户允许控制手机”。

A05 会话抽屉
- 从左侧滑出的全高抽屉，宽度 86%，背景白色，顶部圆角 24dp。
- 顶部：CatfeeAgents 标题、设置按钮、关闭按钮。
- 主按钮“+ 新建会话”，黑色底。
- 搜索框：“搜索标题、摘要或结果…”。
- 分段筛选：最近 / 置顶 / 收藏 / 归档。
- 会话行：
  - 左侧聊天气泡图标（红色 8% 底）
  - 标题、摘要、时间、tokens、ctx、耗时、消息数
  - 置顶/收藏/归档图标
  - running 绿点 + “running”
  - 右侧更多菜单
- 会话行菜单：置顶/取消置顶、收藏/取消收藏、归档/恢复、重命名、
  导出 Markdown、删除（红色）。
- 长列表可滚动；搜索无结果、空列表要有明确空状态。
- 抽屉禁止下滑关闭，只能点关闭或返回。

A06 设置-模型
- 设置使用全屏二级页，不要用可下滑关闭的 Bottom Sheet。
- 顶部固定：返回按钮、标题“设置”、当前模式徽章（完整模式/无障碍模式/仅聊天模式）、关闭。
- 顶部能力条：无障碍 / 手势 / 截图 / Root / 悬浮窗，每项有状态点与“已就绪/未开启”。
- 悬浮状态窗开关 + 说明 + “授予悬浮窗权限”入口。
- 分段 Tab：模型 / 控制台 / 记忆 / 统计 / 关于。
- 模型页：
  - 区块“接口”：Base URL、API Key（掩码显示 + 眼睛按钮）、模型 ID。
  - 次按钮“拉取模型列表”，主按钮“保存模型配置”。
  - 连接结果提示（成功绿色 / 失败红色）。
  - 可用模型列表：单选行，当前模型高亮。
  - DECISION 加速卡：开关、说明、Base URL、Key（掩码）、模型、
    最小置信度、最多连续快速步、测试连接、保存 DECISION 配置、底部说明。

A07 设置-控制台
- 顶部“Web 控制台”标题 + 启用开关。
- 说明“日志、任务和远程指令统一走内置控制台，不再使用第三方 JWT。”
- 控制台地址、设备名称。
- 一次性注册码卡：说明“在 Web 控制台「设备」页生成，绑定成功后立即失效”，
  注册码输入框 + “绑定”按钮。
- 操作行：测试连接、保存配置。
- 状态卡：已连接/已绑定、设备 ID（等宽）、最近状态。
- 已绑定时显示“解除绑定”（红色文字按钮）。
- 底部说明“设备只保存自己的 deviceId / deviceSecret；Web 撤销设备后长连接立即失效。”

A08 设置-记忆
- 标题“App 记忆”，说明“每个 App 独立；Agent 只注入前 800 字，最多保存 N 字。”
- 右上角“刷新”。
- 记忆列表卡：包名、字数、预览；点击进入编辑。
- 编辑态：包名、返回列表、多行文本域、字数计数（接近上限变警告色）、
  保存（黑底）、删除（红色描边）。
- 空状态：“暂无 App 记忆。Agent 完成后会自动写入，也可以在长任务中让它 memory_write。”

A09 设置-统计
- “总览”卡：会话数、总 tokens、prompt / completion、累计耗时、平均上下文。
- “估算单价（每 1M tokens）”：输入、输出两个输入框；估算金额；保存单价。
- “按会话”：Top 20 列表，标题、模型、tokens、耗时。
- 数字使用等宽 tabular-nums，金额保留 4 位小数。
- 空数据时显示“还没有会话数据”。

A10 设置-关于
- 品牌区：CatfeeAgents、副标题“通用 Agent 工作台”。
- 应用信息卡：版本、Version Code、Application ID。
- 能力状态卡：对话与模型、无障碍操作、ROOT 能力、悬浮状态窗、本地会话与记忆；
  每行有状态点和“已就绪/未开启”。
- 隐私说明卡：本地保存会话/附件/记忆；只有配置模型或控制台后才发送请求；
  Root、无障碍、悬浮窗遵循系统授权。

A11 模型选择面板
- 底部 Sheet，顶部标题“本会话模型”，说明“只影响当前会话；全局默认在 设置 → 模型 修改。”
- 选项“跟随全局默认（当前模型名）”，下面列出可用模型。
- 当前项右侧有勾选标记。
- 空列表提示“还没有拉取模型列表。可以在 设置 → 模型 点「拉取模型列表」后回到这里切换。”
- 右上角关闭；禁止下滑误关。

A12 图片预览
- 全屏黑底，顶部关闭按钮与页码（如 2 / 5）。
- 图片居中、可双指缩放、可左右翻页。
- 底部显示文件名/大小；不要挤压图片。
- 单击空白或点关闭退出。

A13 悬浮状态条
- 其他 App 上方的轻量胶囊，宽约 300dp，圆角 18dp，白色 96% 不透明，1px 描边。
- 左侧：阶段点（等待模型黄 / 操作中红 / 已暂停紫 / 完成绿 / 失败红）。
- 中间：阶段名、第 N 步、耗时、最后动作一句话。
- 右侧：暂停/继续、停止两个小按钮。
- 可拖动，避免遮挡状态栏和输入框。
- 设计展开态与收起态。

A14 关键状态合集
请在同一页生成状态组件板：
- 设备模式：完整模式 / 无障碍模式 / 仅聊天模式
- 能力标签：无障碍、手势、截图、Root、悬浮窗；已就绪/未开启
- 聊天：空、流式、等待授权、运行中、暂停、完成、失败、被停止
- 会话：普通、置顶、收藏、归档、running、空搜索
- 控制台：未绑定、绑定中、已连接、连接失败、已撤销
- 按钮：主按钮、次按钮、危险按钮、禁用态、加载态

【必须包含的菜单与操作】
- 顶部菜单：打开会话抽屉。
- 会话抽屉：新建会话、设置、搜索、最近/置顶/收藏/归档、会话行更多菜单。
- 会话行更多：置顶/取消置顶、收藏/取消收藏、归档/恢复、重命名、
  导出 Markdown、删除。
- 消息长按：复制、引用回复、编辑并重新生成（用户）、重新生成（助手）、从这里分支。
- 输入区：附件、发送、暂停、继续、停止、模型切换、取消引用、移除附件。
- 设置：模型配置、拉取模型、保存、DECISION 开关与配置、控制台绑定/解绑、
  记忆编辑/删除、单价保存、能力与隐私查看。
- 授权卡：允许、拒绝。

【交互要求】
- 设置页与会话抽屉禁止下滑关闭；关闭使用明确的返回/关闭按钮。
- 发送后输入框清空，附件和引用一起清空。
- 运行中发送按钮变成暂停+停止；暂停后暂停按钮变成继续。
- 长按消息才出现操作面板，不要每條消息常驻一排按钮。
- 步骤卡默认折叠到 3 行，点击展开。
- 所有危险操作（删除会话、解除绑定、停止任务）需要二次确认。
- 长文本、长包名、长模型名不能撑破布局。
- 键盘弹起时输入区跟随上移，消息列表贴底。
- 不要生成真实 API Key；示例用 `sk-••••••••`。

【输出要求】
1. 先输出一页“设计系统”：颜色、字号、间距、圆角、按钮、标签、输入框、图标规范。
2. 再输出组件页：消息气泡、Activity 卡、步骤卡、授权卡、会话行、设置行、状态标签。
3. 再按 A01–A14 逐页输出高保真 Frame，所有页面使用同一套组件。
4. 使用真实中文文案和合理示例数据，不要 Lorem Ipsum。
5. 不要输出前端代码，不要做营销文案，不要加入登录/注册/付费页。
6. 所有页面必须是可编辑的 Frame，命名清晰，方便开发对照实现。
```

### 2.2 可直接复制的提示词
